## [Cursor Composer 2 released, later admits using Kimi K2.5 as base model without proper attribution](https://x.com/elonmusk/status/2034941631871455262?s=20) ⭐️ 7.0/10

On March 19, Cursor released its new coding model Composer 2, claiming frontier-level performance and an 86% price reduction. Within 24 hours, developers discovered the internal model ID 'kimi-k2p5-rl' via an API endpoint, revealing it was based on Moonshot AI's open-source Kimi K2.5, a fact later confirmed by Cursor and Elon Musk. This incident highlights significant transparency and licensing compliance issues, as Cursor, a product with $2 billion in annual revenue, failed to attribute the open-source base model as required by Kimi K2.5's license for high-revenue products. It raises questions about ethical practices and proper attribution in the competitive AI coding tool market. The Kimi K2.5 license explicitly requires products with monthly revenue over $20 million to display attribution. Cursor's Composer 2 is described as the first version where the company ran continuous pre-training and used a 'self-summarization' reinforcement learning technique on top of the base model for coding tasks.

**Background**: Cursor is an AI-powered code editor that integrates AI models to assist with programming. Kimi K2.5 is an open-source, multimodal agentic model developed by Chinese company Moonshot AI, known for its long context length. It is built on a Mixture-of-Experts (MoE) architecture and was pretrained on a massive dataset of visual and text tokens. In the AI industry, it's common to fine-tune or further train existing open-source foundation models for specific tasks like coding.
