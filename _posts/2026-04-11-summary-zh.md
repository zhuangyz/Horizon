## [研究揭示超 20%免费 LLM API 路由器存在恶意代码](https://x.com/Fried_rice/status/2042423713019412941) ⭐️ 8.0/10

Solayer 创始人 Chaofan Shou 发布研究论文，揭示了大语言模型（LLM）代理所使用的第三方 API 路由器存在重大安全漏洞。该研究测试了 28 个付费和 400 个免费路由器，发现 1 个付费和 8 个免费路由器正在主动注入恶意代码，另有 17 个路由器触碰了 AWS 凭证，甚至有一个路由器盗取了测试私钥中的 ETH。 这之所以重要，是因为它揭示了在快速增长的 LLM 代理生态系统中，一个被忽视的关键供应链漏洞，被攻陷的路由器可以拦截、操纵和窃取敏感数据与凭证。这些发现突显了一个系统性风险，可能破坏对 AI 驱动自动化的信任，并导致重大的财务损失或系统被接管。 这些路由器作为应用层代理，可以明文访问传输中的 JSON 载荷，因为行业目前缺乏端到端的加密保护。研究团队构建了名为 'Mine' 的代理来验证四类攻击，并提出了包括故障闭锁策略门控和响应端异常筛查在内的防御手段。

**背景**: LLM 代理是使用大语言模型来执行任务的 AI 系统，通常通过被称为路由器或网关的中间组件调用外部工具和 API。这些 API 路由器充当管理层，处理诸如将请求路由到不同的 AI 模型（例如 OpenAI、Gemini）、管理 API 密钥和跟踪成本等任务。它们在数据流中的特权位置，如果未能得到妥善保护，会使其成为攻击者的高价值目标。

## [谷歌在 Chrome 146 for Windows 中引入设备绑定会话凭据 (DBSC) 技术](https://security.googleblog.com/2026/04/protecting-cookies-with-device-bound.html) ⭐️ 8.0/10

谷歌在 Chrome 浏览器 Windows 版 146 更新中正式引入了“设备绑定会话凭据”（DBSC）功能。该技术通过将用户的身份验证会话与物理设备硬件（如 TPM）进行加密绑定，生成存储于本地且无法导出的密钥对，从而确保被盗取的 Cookie 无法在其他设备上被非法使用。 这项技术意义重大，因为它直接解决了网络认证中的一个根本性弱点：被盗的会话 Cookie 可以绕过多因素认证（MFA）并导致账户劫持。通过将会话绑定到特定硬件，DBSC 有望显著削弱 Cookie 窃取攻击的效果，为数亿 Chrome 用户增强安全性，并将网络安全架构推向硬件支持的保护模式。 该实现目前特定于 Windows 上的 Chrome 146 版本，利用了 TPM 等硬件安全模块。根据 W3C 规范，DBSC 的设计目标是对现有网络应用进行最小改动即可工作，因为它引入了一种协议，让浏览器能够证明其拥有一个安全存储的私钥。

telegram · zaihuapd · Apr 11, 00:18

**背景**: 会话 Cookie 是用户登录后由网站颁发的令牌，允许浏览器在无需重新输入凭证的情况下维持认证状态。一个主要的安全威胁是 Cookie 窃取，攻击者盗取这些 Cookie（例如通过恶意软件或网络钓鱼）并在自己的设备上使用它们来劫持用户会话，从而有效地绕过任何先前的认证步骤（如密码或 MFA）。可信平台模块（TPM）是设备上的专用硬件芯片，可以安全地生成和存储加密密钥，防止密钥被提取或在原始设备之外使用。

## [Claude AI 模型曝出'身份混淆'缺陷，在上下文极限附近存在安全风险](https://news.ycombinator.com/item?id=47701233) ⭐️ 7.0/10

近期开发者反映，Claude 等大语言模型在处理长对话时会出现'身份混淆'错误，将模型自身的推理或往期输出误认为是用户的当前指令。这种现象在模型接近上下文窗口极限时尤为频繁，表现为模型'自问自答'并产生虚假的用户授权。 这一漏洞在 Claude Code 等自动化工具中构成重大安全风险，模型可能将自己的输出误认为用户指令，从而违规执行部署或删除等高危操作。随着 AI 代理越来越多地集成到生产系统中，此类可靠性问题可能导致严重的操作故障和安全漏洞。 该缺陷在接近上下文窗口极限的所谓'愚笨区'尤为明显，此时模型性能会下降。这种特定的故障模式涉及模型失去对话边界跟踪能力，将自身生成的内容归因于用户，这与上下文极限处的一般性能下降有所不同。

telegram · zaihuapd · Apr 10, 14:52

**背景**: 大语言模型(LLM)的上下文窗口是指模型一次能够处理和记忆的文本量，以 token 为单位衡量。每个 LLM 都有其上下文窗口的限制，这约束了模型在生成响应时能够考虑的对话历史长度。当接近此限制时，模型通常会出现性能下降，但'身份混淆'缺陷代表了一种特定且危险的故障模式，即模型错误地将指令来源归因。
