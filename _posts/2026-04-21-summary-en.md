## [EU enforces new smartphone/tablet regulations: 800 battery cycles with ≥80% health, 5+ years of system support](https://t.me/zaihuapd/40973) ⭐️ 8.0/10

The European Union announced that starting June 20, 2025, all smartphones and tablets sold in the EU must display an upgraded EPREL energy label and meet specific durability requirements. These requirements include maintaining at least 80% battery health after 800 charge cycles and providing over five years of operating system support. This regulation will force manufacturers to design longer-lasting devices, potentially reducing electronic waste and saving consumers money on replacements. It represents a significant shift in consumer electronics policy, prioritizing product longevity and repairability over rapid replacement cycles, and could influence global manufacturing standards. The new EPREL label covers seven key metrics, including energy efficiency grade (A-G), battery cycle durability, drop resistance, repairability score, and IP rating for dust/water resistance. The battery durability standard of ≥80% capacity after 800 cycles is notably higher than many current industry practices, which often see significant degradation earlier.

**Background**: The European Product Registry for Energy Labelling (EPREL) is a public EU database for the energy efficiency and environmental performance of products. Battery cycle durability refers to the number of complete charge-discharge cycles a battery can undergo before its capacity falls below a specified percentage of its original capacity. An IP (Ingress Protection) rating is a standard that classifies the degree of protection provided by an enclosure against intrusion from solids and liquids.

## [Claude Desktop Silently Registers Native Messaging Manifests in Multiple Chromium Browsers](https://www.thatprivacyguy.com/blog/anthropic-spyware) ⭐️ 8.0/10

The Anthropic Claude Desktop application, upon installation on macOS, automatically creates a native messaging manifest file named 'com.anthropic.claude_browser_extension.json' in the NativeMessagingHosts directories of seven different Chromium browser paths within the user's home directory. This operation occurs without user consent or notification, and the manifest file is rewritten each time the application runs, even if the corresponding browsers are not installed. This behavior is significant because it modifies browser configurations silently, enabling browser automation capabilities like opening tabs, sharing login states, reading the DOM, and filling forms without explicit user approval. It raises serious security and privacy concerns, as it creates a potential attack vector and demonstrates a lack of transparency from a major AI company regarding its desktop application's integration with web browsers. The manifest file points to a binary at '/Applications/Claude.app/Contents/Helpers/chrome-native-host' and pre-authorizes three specific Chrome extension IDs to call the host with user permissions. Anthropic's public documentation does not mention this bridging feature for the desktop app, only for Claude Code, despite the significant automation capabilities it enables.

telegram · zaihuapd · Apr 21, 08:36

**Background**: Native Messaging is a Chrome/Chromium feature that allows browser extensions to communicate with native applications installed on the user's computer. The native application (host) is registered via a manifest file placed in a specific directory (e.g., NativeMessagingHosts within the user's profile). This mechanism is used for tasks that require deeper system integration, such as browser automation tools. However, write access to the NativeMessagingHosts directory is a known security consideration, as it could be exploited to redirect execution to malicious binaries.

## [Critical architecture flaw in Anthropic's Model Context Protocol threatens 1.5B downloads and 200K servers](https://cybersecuritynews.com/anthropics-mcp-vulnerability/) ⭐️ 8.0/10

Security researchers from OX Security disclosed a fundamental design vulnerability in Anthropic's official Model Context Protocol (MCP) SDKs, which could allow remote code execution (RCE). The vulnerability, stemming from a systemic command injection flaw, has propagated across the AI ecosystem, potentially affecting up to 200,000 servers and over 1.5 billion downloads. This is significant because MCP is a foundational open standard introduced by Anthropic to connect AI models with external data and tools, making the vulnerability systemic across the entire AI application stack. The massive scale of potential impact (1.5B downloads) and the vendor's controversial stance of rejecting protocol-level fixes heighten the risk for countless AI-powered applications and services relying on these frameworks. The research has generated at least 10 distinct CVE identifiers, affecting major AI frameworks like LangChain and IBM LangFlow. While some downstream vulnerabilities have been patched, Anthropic has reportedly rejected suggestions for a protocol-level fix, characterizing the behavior as "expected."

MCP operates on a client-server architecture, where servers provide context (like data or tools) to AI applications (clients).
