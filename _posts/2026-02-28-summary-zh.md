**背景**: Gemini 是由 Google DeepMind 开发的大型语言模型（LLM）系列。Gemini Nano 是该系列中一个更小、更高效的版本，专门设计用于在设备端运行，例如在 Android 的 AICore 或 Chrome 浏览器内部。Prompt API 是一个新的内置浏览器 API，它允许 Web 应用程序访问本地的 Gemini Nano 模型，以执行摘要等任务，而无需将数据发送到外部服务器。
