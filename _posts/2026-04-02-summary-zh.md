一份报告披露，当用户在基于 Chrome 的浏览器中加载 LinkedIn 网站时，其 JavaScript 会自动执行一次扫描，通过唯一 ID 探测数千个特定的浏览器扩展，收集结果、加密并将此数据发送到 LinkedIn 的服务器。这种扫描在用户未收到通知或未明确同意的情况下发生，且未在 LinkedIn 的隐私政策中提及。 这一做法代表了一个主要职业社交平台的重大隐私侵犯，可能实现详细的浏览器指纹识别，从而跨网站追踪用户。它在未经透明告知的情况下收集有关用户习惯、信仰和可访问性需求的敏感个人数据，引发了关于知情同意以及是否符合 GDPR 等数据保护法规的严重法律问题。 扫描不仅限于专业或与 LinkedIn 相关的工具；据报道，它能检测到与宗教内容过滤（例如，遵循伊斯兰价值观的 PordaAI）、政治标签（例如，反犹太复国主义标签）以及为神经多样性用户设计的工具（例如，simplify）相关的扩展。数据传输是加密的，这种做法似乎是现代浏览器指纹识别技术的一部分，该技术通过聚合许多弱信号来创建唯一的用户标识符。

hackernews · digitalWestie · Apr 2, 13:09

**背景**: 浏览器指纹识别是一种跟踪技术，它收集有关用户浏览器配置的信息（例如已安装的字体、屏幕分辨率和已安装的扩展程序），从而为该设备创建唯一标识符。与 Cookie 不同，指纹识别更难被阻止或清除，因为它依赖于浏览器固有的特性。网站上运行的 JavaScript 可以访问某些浏览器 API 来检测已安装的扩展程序，这是指纹识别中使用的方法之一。主要的数据隐私法规，例如欧盟的《通用数据保护条例》(GDPR)，要求收集个人数据必须获得用户的明确同意。

## [AMD 发布 Lemonade，一款支持 GPU、NPU 和 CPU 统一推理的开源本地 LLM 服务器。](https://lemonade-server.ai/) ⭐️ 7.0/10

AMD 发布了一款名为 Lemonade 的开源本地 LLM 服务器，它为文本、图像和音频模型提供了统一的推理服务。该服务器支持在 GPU（通过 ROCm 或 Vulkan）、NPU 和 CPU 上执行，旨在简化多模态 AI 模型在本地硬件上的部署。 这很重要，因为它直接解决了 AMD 硬件用户面临的一个主要痛点，即运行本地 AI 模型的生态历来是碎片化且复杂的。通过提供一个官方支持的统一服务器，AMD 正在降低本地 AI 推理的入门门槛，并推动其硬件成为开发者和爱好者可行的 AI 平台。 一个关键的技术细节是，Lemonade 所使用的 NPU 模型和内核是专有的，并非开源，这可能会限制社区对该硬件的驱动优化。该服务器的定位不仅仅是一个模型服务器，其目标是处理跨多种 AI 模态（文本、图像、音频）的编排，而这在本地部署中通常是一个复杂的挑战。

hackernews · AbuAssar · Apr 2, 11:04

**背景**: 在本地运行大语言模型需要专门的软件服务器，如 Ollama 或 LM Studio，来管理模型加载、推理和硬件加速。NPU（神经网络处理单元）是专为高效 AI 推理设计的处理器，对于 LLM 推理等重复性任务，其功耗通常远低于 GPU，但对于多样化工作负载的灵活性可能较差。统一推理指的是一个能够通过单一接口处理多种类型 AI 模型（文本、视觉、音频）的系统，从而降低系统复杂性。

## [瑞典逆转数字化课堂政策，优先使用书本和手写而非屏幕。](https://undark.org/2026/04/01/sweden-schools-books/) ⭐️ 7.0/10

瑞典正在实施一项重大的政策转变，在课堂上放弃笔记本电脑和平板电脑等数字工具，回归传统的书本和手写。这一逆转涉及大量投资，据报道约 1000 亿卢比，用于用实体学习材料取代屏幕。 此举挑战了全球数字优先教育的趋势，并引发了一场关于技术在教学法中基于证据的作用的关键辩论。它表明政策制定者和家长越来越担心过长的屏幕时间对儿童的注意力、认知发展和学习成果可能产生的负面影响。 这一政策转变质疑最初推动数字化的举措是否基于证据，批评者指出当前的逆转也可能缺乏坚实的证据基础，代表了一种潜在的“氛围转变”。在邻国芬兰也观察到了类似的趋势，那里的学校也正在回归纸质书本，这是基于家长认为书本比屏幕更有利于学习的共识。

hackernews · novaRom · Apr 2, 10:50

**背景**: 从 2000 年代末开始，瑞典的课堂经历了显著的数字化，传统教科书逐渐被笔记本电脑和平板电脑取代。数字工具成为基础教育中自然而然的一部分，学习从纸质形式转向基于屏幕的形式。研究表明这种转变可能存在弊端，例如“视频缺陷”，即幼儿从屏幕中学到的东西少于从现实互动中学到的；同时有证据表明，手写对记忆和学习具有独特的认知益处，是打字无法比拟的。
