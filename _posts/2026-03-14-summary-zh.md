## [Anthropic 为 Claude Opus 和 Sonnet 4.6 全面开放 100 万上下文窗口，且无额外溢价。](https://simonwillison.net/2026/Mar/13/1m-context/#atom-everything) ⭐️ 8.0/10

Anthropic 已为其 Claude Opus 4.6 和 Sonnet 4.6 模型全面开放了 100 万 token 的上下文窗口。关键在于，该公司对完整的 100 万窗口均采用标准定价，取消了之前收取的长上下文溢价。 此举代表了 LLM 市场一次重大的竞争格局转变，因为 OpenAI (GPT-5.4) 和 Google (Gemini 3.1 Pro) 等主要竞争对手分别对超过 27.2 万和 20 万 token 的提示收取溢价。通过以无额外成本提供大得多的上下文窗口，Anthropic 直接挑战了现行的定价模式，并可能迫使其他供应商效仿。 此变更专门适用于 Opus 4.6 和 Sonnet 4.6 模型版本。此前，当使用扩展上下文窗口时，Anthropic 的 API 定价会自动对超过 20 万输入 token 的请求应用溢价费率，这可能导致成本增加近一倍。

rss · Simon Willison · Mar 13, 18:29

**背景**: 大型语言模型 (LLM) 中的上下文窗口是指模型在单次输入中能够处理的、以 token 衡量的最大文本量。它决定了模型一次性能“记住”和参考多少信息。更大的上下文窗口使得模型能够一次性完成分析整本书、冗长文档或大型代码库等任务。历史上，处理如此长的上下文需要显著更多的计算资源，导致供应商收取额外费用，即所谓的“长上下文溢价”。

## [研究称支付宝 DeepLink 功能或可通过 JSBridge API 调用导致个人信息泄露](https://innora.ai/zfb/) ⭐️ 7.0/10
